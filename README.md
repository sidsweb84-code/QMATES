# STEAL A CRITTER (license-ready "STEAL POKÉMON" framework)

A complete multiplayer Roblox tycoon/stealing game inspired by the
*Steal a Brainrot* loop. You own a base, buy collectible creature cards from a
moving conveyor, earn passive income, defend your base, sneak into other bases
to steal their best cards, rebirth for permanent multipliers, and fill your
collection book.

> **Licensing.** This project ships with **75 original creatures**, original
> names, procedurally built 3D models, original UI/card art, and only the
> placeholder sounds bundled with the Roblox client. It contains **no Pokémon
> names, artwork, card scans, models or audio**. The title shown in game is
> **"STEAL A CRITTER"**. Everything is structured so that properly licensed
> Pokémon content can be dropped in later, but **only switch
> `ContentConfig.LicensedMode` on if you hold written permission from the
> rights holders** (The Pokémon Company / Nintendo / Game Freak / Creatures).
> Publishing Pokémon content commercially without a license is not safe. See
> [docs/LICENSING.md](docs/LICENSING.md).

## Quick start

There are two ready-made files in `build/`. Use **one** of them.
To download one from GitHub, open the file on the
`claude/fervent-goldberg-9vaklp` branch and click **Download raw file**
(don't use "Save link as", which saves a web page).

**Option A — one place file (easiest): `build/StealPokemon.rbxl`**

1. In Roblox Studio: **File → Open from File…** and pick `StealPokemon.rbxl`.
2. The 3D view is empty: that's expected. The map is generated by the server
   when the game starts. Press **Play**.
3. To try stealing with several players: in the dropdown next to the Play
   button pick **Server & Clients**, set 2 clients, then start it
   (older Studio: *Test tab → Clients and Servers*).
4. Optional, to keep progress between Studio sessions: publish the place
   (**File → Publish to Roblox**), then **File → Experience Settings →
   Security → Enable Studio Access to API Services** (older Studio: *Home →
   Game Settings*). Without it the game uses an in-memory test DataStore and
   says so in its Settings window.

**Option B — one model file: `build/StealPokemon_Installer.rbxm`**

Use this to put the game into a **new Baseplate place** (or a place that has
no other game in it).

1. Open the place in Studio (Edit mode, not playing).
2. Drag `StealPokemon_Installer.rbxm` into the 3D view (or right-click
   **Workspace → Insert from File…**). It appears in the Explorer as
   `Workspace.StealPokemon_Installer`.
3. Open the **Command Bar**: **Script tab → Command Bar** (or **Ctrl+9**,
   **Cmd+9** on Mac). Paste this line, then click **Run** or press
   **Ctrl+Enter** (**Cmd+Enter** on Mac). In older Studio, Enter runs it.

   ```lua
   require(workspace.StealPokemon_Installer.StealPokemon_Install)()
   ```

4. The **Output** window (Script tab → Output) should say
   `✅ Installed 10 items`. If nothing was printed, the line didn't run.
5. The 3D view is now empty (the Baseplate was moved away): that's expected.
   Press **Play** and the map is built.

What the installer does: moves every script into ReplicatedStorage,
ReplicatedFirst, ServerScriptService and StarterPlayerScripts, applies the
place settings (these are overwritten), and removes itself. The template
Baseplate/SpawnLocation (they would overlap the generated map) and **anything
already using one of the game's names** (`Shared`, `Remotes`, `Modules`,
`Services`, `UI`, …, e.g. an older install) are **moved, not deleted**, to
`ServerStorage.StealPokemon_Backup_<time>`. Your own
`ReplicatedStorage.Assets` (e.g. licensed models) is kept. To undo, click the
3D view and press **Ctrl+Z** (**Cmd+Z** on Mac).

Troubleshooting:

* *"StealPokemon_Installer is not a valid member of Workspace"* right after
  `✅ Installed` means it's already installed: just press Play. Otherwise make
  sure the `StealPokemon_Installer` folder sits directly under Workspace.
* *"Stop the game first"*: press Stop and run the line again.
* Pressing Play before installing does nothing except print
  "Not installed yet" (the game only starts from ServerScriptService).

**Option C — live-sync with Rojo** (for development)

```bash
./scripts/setup-tools.sh            # downloads rojo, luau, luau-lsp into ./tools
tools/rojo serve                     # then "Connect" from the Rojo Studio plugin
./scripts/build.sh                   # rebuild both files in build/
./scripts/test.sh                    # type check, unit tests, simulation, build checks
```

Before publishing, follow **[docs/SETUP.md](docs/SETUP.md)** (gamepass and
product IDs, admin UserIds, audio, max players).

## What's in the game

| System | Highlights |
| --- | --- |
| **Collectibles** | 75 original creatures across 12 elements and 9 rarities (Common, Uncommon, Rare, Epic, Legendary, Mythic, Divine, Secret, Limited), each with price, income, sell value, steal difficulty, spawn weight, category, card art, idle animation, sounds. Defined in `CollectibleConfig`. |
| **Mutations & traits** | Normal, Golden, Diamond, Rainbow, Shadow, Crystal, Glitched, event-only Cosmic; traits Investor/Lucky/Speedster/Guardian/Jackpot. Multipliers in `MutationConfig` / `TraitConfig`. |
| **Conveyors** | Main conveyor + rebirth-gated Elite conveyor. Server rolls items with weighted odds; clients animate them locally; purchases are validated server-side (distance, cash, item still there). |
| **Acquisition reveals** | Five reveal tiers: quick pop for Commons up to a full-screen sequence with server-wide announcement for Secret/Limited. |
| **Bases** | 8 plots, each with spawn, entrance, slots (6 → 30 by base level), cash display, lock door, collect pad, upgrade/rebirth stations, sign, security light, traps. |
| **Income** | One central server tick. Manual collect pad, auto-collect upgrade, offline earnings (15% for up to 8h). |
| **Stealing** | Two phases: *grab* (hold, duration scales with rarity) then *carry* home (slowed, visible). Owner catches the thief by touching them; traps stun; locks block; alarms alert. Cooldowns per pair, on failure, and anti-steal protection for victims; new players are protected for 10 minutes of playtime. Fully server-authoritative. |
| **Defenses** | Base lock (longer with Security upgrades), alarm levels, traps, anti-steal cooldown, theft detection alerts. |
| **Upgrades** | Base levels (slot capacity), per-card levels, security/alarm/traps/anti-steal/auto-collect tracks, storage. `UpgradeConfig`. |
| **Rebirth** | Cost grows ×3.2; each rebirth gives +25% income and +5% luck, unlocks Elite conveyor, bigger packs, milestone rewards; keeps your best cards (3/6/10 by milestone). `RebirthConfig`. |
| **Luck** | Transparent: the Index → Odds tab shows the exact live odds (including boosts/events) using the same `Odds` module the server rolls with. |
| **Events** | Double Cash, Lucky Hour, Legendary Rush, Rainbow Event, Shiny Weekend, Halloween/Winter/Summer seasonal, Celebration. Auto-rotation, weekend and date-based seasonal events, admin control. `EventConfig`. |
| **Shops** | Card packs (cash only, odds shown), boosts, cosmetics (trails, name tags, card frames, base themes, effects), event shop (event currency), Robux store. |
| **Currencies** | Cash, Tokens, event currency (Candy/Snowflakes/Shells/… per event). |
| **Rewards** | 7-day daily streak, playtime milestones, collection milestones (25/50/75/100%), tutorial rewards. |
| **Quests** | 3 daily quests from a pool of 12 (one free reroll), 9 lifetime achievement series. |
| **Collection book** | Every creature × mutation discovered, completion %, rewards. |
| **Leaderboards** | `leaderstats` (Cash, Rebirths, Steals) plus global OrderedDataStore boards (cash/sec, cash, rebirths, collection, rare finds, steals, playtime) shown in the hub and in the UI. |
| **Social** | Player list with inspect + visit base, server announcements, showcases, optional secure trading (both sides confirm, countdown, re-validated on completion). |
| **Monetization** | Gamepasses (VIP, +5 slots, fast walk, collector vault, name tag, base effects, exclusive cosmetics) and developer products (cash bundles scaled to income, boosts, server luck). Central `MonetizationConfig`, `ProcessReceipt` with receipt de-duplication and save-before-grant. Nothing sold that only paying players can obtain in power. |
| **Onboarding** | 7-step guided tutorial with world markers and rewards. Can be skipped. |
| **Saving** | DataStore with session locking, autosave every 60s, save on leave and shutdown, retries with backoff, schema versioning + migrations, validation. |
| **Security** | Every remote goes through one validated, rate-limited gateway; server owns cash, ownership, thefts, purchases, rewards. Anti-speed/teleport checks, suspicion scoring and admin logs; no automatic permanent bans. |
| **Admin** | In-game 🛠️ admin panel and chat commands (see below), server-side permission check. |
| **UI** | Responsive for PC, mobile, tablet and console (virtual canvas with automatic scaling, gamepad navigation, touch-sized buttons, keyboard shortcuts). Settings for music, SFX, graphics quality, reduced motion, floating card labels, interface size and tutorial tips. |

## Admin commands

Admins are configured in `src/ServerScriptService/Modules/AdminConfig.luau`
(UserIds or a group rank). In Studio every tester is an admin by default.
Use the **🛠️ Admin** button in the HUD (reliable on every chat version) or
type commands in chat.

| Command | Description |
| --- | --- |
| `/help` | List commands |
| `/givecash <player\|me\|all> <amount>` | Give cash (accepts `1.5m`, `2b`, …) |
| `/givetokens <player> <amount>` | Give tokens |
| `/giveitem <player> <id> [mutation] [trait]` | Give a collectible |
| `/spawn <id> [mutation] [trait] [Main\|Elite]` | Spawn a specific card on a conveyor |
| `/event <start\|stop\|list\|clear> [EventId] [minutes]` | Control events |
| `/setluck <multiplier> [minutes]` | Server luck multiplier |
| `/setincome <multiplier> [minutes]` | Server income multiplier |
| `/announce <message>` | Filtered server-wide announcement |
| `/kick <player> [reason]` | Kick |
| `/teleport <player> [target\|hub\|elite\|base]` (alias `/tp`) | Teleport |
| `/boost <player> <Income\|Luck\|Speed\|Protection> <seconds>` | Personal boost |
| `/setrebirths <player> <n>` | Set rebirths |
| `/logs [category] [count]` | Recent server logs |
| `/report <player>` | Anti-exploit suspicion report |
| `/save <player>` | Force save |
| `/resetcooldowns` | Clear steal cooldowns |
| `/resetdata <player>` | *(Studio only)* wipe data |
| `/testproduct <ProductKey>` / `/testpass <PassKey> [off]` | *(Studio only)* simulate purchases |
| `/runtests` | Run the in-game integration test suite |

`player` accepts `me`, `all`, `others`, or the start of a username / display name.

## Placeholders you must replace before publishing

* **Gamepass / developer product IDs** — all `Id = 0` in `MonetizationConfig`
  (items with `Id = 0` show as "coming soon" and cannot be bought).
* **Audio** — `SoundConfig` uses the sounds bundled with the Roblox client;
  music is empty. Upload your own or licensed audio.
* **Admin UserIds** — `AdminConfig.UserIds` is empty.
* **Icons/thumbnails/game page art** — not included.
* **Licensed content** — only if you obtain a license (see LICENSING).
